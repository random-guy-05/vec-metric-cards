## Title
VEC Metric Cards - nine visual reference cards for the official scoring metrics

## What it is, in a line
Nine portable reference cards explaining each official ranking metric.

## What it is, and who it helps
A nine-card visual reference deck that explains every official ranking metric in plain language while preserving the current scoring contract. Each card states the metric name/function key, tasks where it ranks, optimization direction, official question/weight context, what the metric rewards, a common failure pattern, and a practical debugging move. Cards cover DES/de_score, DCS/de_direction, MMD/mmd_u, CSS/variogram, SDD/d2_shape, ODS/occupancy_dice, TSR/scale_log_ratio, NFS/neighborhood_mmd, and severity_slope. The resource is intentionally different from runnable scorer notebooks: it is a portable visual reference for Slack, workshops, lab meetings and day-to-day model debugging, with editable SVG, PNG and PDF outputs plus a combined deck.

## How someone else uses it
Open the repository and use the ready-made PNG/PDF assets, or edit the source SVG files. No Challenge data, sign-in, or Python environment is required to use the finished visuals.
