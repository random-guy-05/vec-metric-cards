# VEC Metric Cards

Nine source-linked visual reference cards for the official Virtual Embryo Challenge ranking metrics.

## Cards

- DES / `de_score` - DE gene recovery
- DCS / `de_direction` - change direction
- MMD / `mmd_u` - cell-state distribution
- CSS / `variogram` - gene-gene co-variation
- SDD / `d2_shape` - 3D shape distance
- ODS / `occupancy_dice` - occupied-volume overlap
- TSR / `scale_log_ratio` - tissue growth scale
- NFS / `neighborhood_mmd` - local spatial organisation
- `severity_slope` - perturbation response magnitude

Each card is available as editable SVG, PNG, and PDF. `VEC_METRIC_CARDS.pdf` combines the complete deck. The cards explain the current metric contract; the official evaluation page remains authoritative.
